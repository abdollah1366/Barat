# حسابداری برات

برنامه حسابداری ساده، سبک و زیبا برای ویندوز، با رابط کاملاً فارسی و راست‌چین.
بر اساس فایل اکسل «صورت حساب مورخه» ساخته شده است: متراژ، خرید، فروش متری، جمع فاکتور، هزینه، سود، نقد و چک.

## امکانات

- **فاکتور فروش** با تاریخ شمسی، مشتری و چند قلم کالا. جمع و سود هر ردیف خودکار حساب می‌شود:
  `جمع = فروش متری × متراژ` و `سود = (فروش − خرید) × متراژ − هزینه`
- **دریافتی‌ها**: نقد یا چک (شماره، بانک، سررسید) و نمایش مانده هر فاکتور
- **چک‌ها**: لیست چک‌های در انتظار، وصول‌شده و برگشتی و هشدار سررسید
- **داشبورد**: فروش، سود و دریافتی امروز و این ماه، چک‌های نزدیک سررسید
- **مشتری‌ها** با جمع خرید و مانده حساب، **کالاها** با قیمت پیش‌فرض خرید و فروش
- **گزارش** بازه دلخواه، فروش روزانه و بر اساس کالا
- **خروجی اکسل** به همان شکل صورت حساب قدیمی (با فرمول)
- چاپ فاکتور، تم روشن و تیره، پشتیبان‌گیری و بازگردانی با یک کلیک
- کاملاً آفلاین. اطلاعات در یک فایل SQLite در پوشه `%APPDATA%\Barat` ذخیره می‌شود

## اجرا در VS Code

پیش‌نیاز: [Node.js](https://nodejs.org) نسخه ۲۰ یا بالاتر و [Git](https://git-scm.com).

1. در VS Code کلید `Ctrl+Shift+P` را بزنید، `Git: Clone` را انتخاب کنید و آدرس مخزن را بدهید:
   `https://github.com/abdollah1366/Barat`
2. در ترمینال VS Code (`` Ctrl+` ``):

```bash
npm install
npm run dev
```

برنامه باز می‌شود و با هر تغییر در کد، صفحه خودکار به‌روز می‌شود. در حالت توسعه با `F12` ابزار دیباگ باز می‌شود.

## ساخت فایل نصبی ویندوز

```bash
npm run dist
```

خروجی در پوشه `release` ساخته می‌شود:
- `Barat Setup 1.0.0.exe` فایل نصبی
- `Barat 1.0.0.exe` نسخه قابل‌حمل (بدون نصب)

## ساختار پروژه

```
electron/
  main.cjs      پنجره برنامه، پشتیبان‌گیری، ارتباط با رابط کاربری
  db.cjs        دیتابیس و همه محاسبات (SQLite با sql.js)
  excel.cjs     خروجی اکسل
  preload.cjs   پل امن بین رابط کاربری و برنامه
src/
  App.jsx       منوی کناری و صفحه‌ها
  views/        داشبورد، فاکتورها، چک‌ها، مشتری‌ها، کالاها، گزارش‌ها، تنظیمات
  components/   اجزای مشترک (پنجره، ورودی عدد و تاریخ، پیام)
  lib/util.js   تاریخ شمسی و قالب‌بندی اعداد
  styles.css    ظاهر برنامه
```

## میانبرها

- `Ctrl+S` در فرم فاکتور: ذخیره
- `Esc`: بستن پنجره
- دابل‌کلیک روی فاکتور: ویرایش
- در ورودی تاریخ می‌توانید با ارقام فارسی یا انگلیسی بنویسید، مثل `1404/8/3`
